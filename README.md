# Abby's Portfolio

Hi! I'm Abby. This is my personal portfolio website — a little corner of the internet about me and the things I love.

## View it live

The site is deployed with GitHub Pages:

**https://aaleyiah.github.io/Abby-Portfolio/**

## What's on it

- **About Me** — a short intro
- **Things I'm Interested In** — my favorite shows and movies

## How it's built

A single `index.html` file with plain HTML and CSS. No frameworks, no build step — just open it in a browser.

## Making changes

1. Edit `index.html`
2. Commit and push to `main`
3. GitHub Pages rebuilds the site automatically (takes a minute or two)
